# Historique des anciens numéros

Dépose ici les anciens numéros de la newsletter, un fichier par numéro
(`.md`, `.txt`, `.html` ou `.eml`), nommé par date : `2026-10-06.md`.

Ils servent à :
- apprendre le style maison des Liens en bref (`/newsletter-brefs` crée `newsletter/style.md`) ;
- ne jamais reproposer une question du jour déjà publiée (`/question-du-jour`) ;
- éviter de retraiter un sujet déjà couvert.
